How this connects

  • Real page: static/login.html, served at /login.
  • You arrive here as /login?next=/visits/V001219 when a page's /api/me call returned 401.
  • Submit sends POST /auth/login with {"email", "password"}.
    • 200: the server sets the session cookie, and the page goes to next (or /visits if there's none).
    • 401: show the error message from the JSON, as above.
