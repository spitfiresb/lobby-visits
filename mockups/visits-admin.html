How this connects

  • Real page: static/visits.html at /visits?from=2026-08-01&to=2026-08-31&page=1. The filters are in the URL, so refresh and shared links keep them.
  • On load, app.js makes three calls:
    1. GET /api/me: 401 sends you to /login?next=…. The role decides whether the nav shows "Users".
    2. GET /api/stats?from=…&to=… fills the headline numbers and the two tables.
    3. GET /api/visits?from=…&to=…&page=1 fills the list (50 rows per page). The total and page count come from the server.
  • The page builds the API URLs by copying its own query string, so the page and the API always agree on the filters.
  • The outage warning appears when the range includes 10–13 Aug (db.missing_days, which the stats response would need to include).
