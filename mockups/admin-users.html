How this connects

  • Real page: static/admin-users.html at /admin/users.
  • Calls GET /api/me. If the role is viewer, the page shows the no access message instead.
  • Then GET /api/users, which returns {"users": [{"email","name","role","signed_up_at"}]}. signed_up_at is null for "Not yet".
  • The real control is in app.py: /api/users returns 403 to a viewer, even from curl.
