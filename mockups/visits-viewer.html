How this connects

  • Same page file and same three API calls as the admin version. The page has no role logic for the table. It shows whatever fields came back.
  • The difference is made in db.py. A viewer's query selects only VIEWER_COLUMNS, so each row in the JSON looks like:
    {"visit_id":"V001211","visit_date":"2026-08-31","signed_in_at":"2026-08-31 09:53:00","signed_out_at":null,"visit_type":"interview","host_team":"Facilities","pre_registered":false}
  • There's no visitor_name, visitor_email, visitor_company or host_name key at all. The "Visitor" text is written by the page, not sent by the API.
